# MACSPLOIT v0.1.0 — public beta (draft release notes)

> Draft. Not yet released. No GitHub Release, tag, or binaries have been published.

## What MACSPLOIT is

A native macOS modular security **reconnaissance and assessment workbench** for
authorized testing. It models an engagement as a durable graph of targets → assets →
relationships → evidence, produced by modular providers and organized into Recon
Chains, with scope enforcement, provenance, and hash-verified evidence — all local,
no telemetry.

## What works in this release (BETA)

- Workspaces, target classification, scope engine, asset graph, evidence, events,
  persistence (all STABLE foundation).
- **Domain Recon** pipeline: Subfinder → native DNS → Nmap → HTTPX, producing
  Domain → Subdomain → IP → Port → Service → Website/Technology assets with
  relationships, provenance, and evidence.
- Fully offline **Synthetic Recon** demo (no network).
- Provider status (installed/missing/built-in), risk labels (passive / low-impact /
  active), timeouts, cancellation, and bounded, shell-free execution.

## What does not work yet (PLANNED)

Web crawling, content discovery, historical URLs, native web analyzers, JavaScript/
API discovery, screenshots, TLS analysis, vulnerability assessment (Nuclei),
findings engine, reporting exports, OSINT, and a Tool Manager installer. See
[features.md](../features.md). Hardware/wireless/lab modules are FUTURE and
intentionally out of the default path.

## Supported platforms

- macOS 13+ (developed/tested on macOS 26, Apple Silicon).
- Apple Silicon primary; Intel expected to build from source but not routinely
  verified.

## Architecture & security

- SwiftUI app ↔ Rust core over a JSON pipe; per-workspace SQLite; provider
  architecture with a shell-free process supervisor.
- Scope is a first-class boundary; active providers only touch in-scope assets.
- Evidence is preserved and SHA-256 verified before parsing.
- See [architecture](../architecture.md), [security model](../security-model.md),
  [threat model](../threat-model.md), [privacy](../privacy.md).

## Provider requirements

Install the external tools you want to use (MACSPLOIT never installs them):
`subfinder`, `nmap`, `httpx`. Native DNS is built in. See the README table.

## Installation

Build from source (see the README). The app is an **ad-hoc-signed local development
build** — not notarized; Gatekeeper will warn on first launch. There are no
prebuilt binaries in this release.

## Known limitations

- The on-screen quit/reopen GUI acceptance walkthrough has not been verified in an
  automated desktop environment; core persistence is verified by automated tests.
- HTTP redirect-based scope re-checks, per-host rate limits, and DNS/scan freshness
  are not yet implemented.
- Intel and older-macOS runtime behavior are unverified.
