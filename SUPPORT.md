# Support

Thanks for using MACSPLOIT. Here is where to go for each kind of request.

| I want to… | Use |
| --- | --- |
| Report a bug | [GitHub Issues](https://github.com/doctordoomies/MACSPLOIT/issues) → **Bug report** |
| Request a feature | [GitHub Issues](https://github.com/doctordoomies/MACSPLOIT/issues) → **Feature request** |
| Propose a new provider | [GitHub Issues](https://github.com/doctordoomies/MACSPLOIT/issues) → **Provider proposal** |
| Ask a usage question | GitHub Issues (or Discussions, if enabled) |
| Report a security vulnerability **in MACSPLOIT** | **Private Vulnerability Reporting** — see [SECURITY.md](SECURITY.md) |

## Please never post publicly

Do **not** paste into public issues or discussions:

- credentials, API keys, tokens, or cookies
- real client/target data, private IPs, or customer information
- captured assessment evidence (scans, PCAPs, etc.)
- undisclosed security vulnerabilities in MACSPLOIT (use Private Vulnerability
  Reporting instead)

Scrub logs and screenshots before attaching them.

## Before filing a bug

- Confirm you are on the latest release or `main`.
- Try the offline **Synthetic Recon** flow to isolate whether the issue is core or
  provider/tool related.
- Include your MACSPLOIT version/commit, macOS version, and architecture.
